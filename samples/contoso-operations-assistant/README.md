# Contoso Operations Assistant sample

This directory contains fictional, synthetic material for local testing. It does not describe a real organization or policy. Phase 3 will ingest these files through the document worker; the phase-2 in-memory search adapter contains equivalent seed facts so the API flow works now.

Suggested questions:

- What is the international travel daily expense limit?
- Which approvals are required for a purchase above 5,000 units?
- How quickly must a suspected security incident be reported?
- Open a support ticket for this issue. (Planned approval workflow.)
